# 外部参考清单（Reuse-First）· 活动记录生成器

> 2026-08-14 调研。**方向已锁**：本项目 = Creative OS 的「活动记录生成器」——读 CO 活动数据、
> 按月留痕、每天看进度，纸质日历 / 非遗拓古（方向②暖·编辑之上的材质升级版 B）。
> 本清单**只供将来决策**，不为并入 CO 做任何改动，不动现有代码。

## 一句话结论

**现有技术栈（pdf-lib + fontkit + 自绘 SVG）已经是这三条线的最优解，外部项目主要作「参考/校准」，不作「替换」。**
唯一值得认真借的是别人的**数据契约**（活动→日强度怎么建模）和**滤镜调参手感**；印刷主线不要换栈。
一个真风险单列在末尾（SVG 滤镜 → 印刷 PDF 的栅格化）。

## ⚠️ 单列的真风险：SVG 滤镜 → 印刷 PDF 的栅格化

拓质靠 SVG 滤镜（feTurbulence/feDisplacementMap）实时生成——**这些滤镜到了印刷 PDF 里不能保持矢量**，
导出前必须先把带滤镜的图层**栅格化成高分位图**（≥300dpi，A1 尺寸下是很大的图）再嵌进 PDF，否则要么滤镜丢失、
要么各家 PDF 渲染器结果不一致。当前 pdf-lib 管线是纯矢量绘制，**尚未处理滤镜栅格化这一步**。
这是「拓质」撞上「印刷级 PDF」的真正落地难点，将来做 B 的印刷导出时要正面解决（不在本次改动范围）。

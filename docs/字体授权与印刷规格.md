# 字体授权 & 印刷规格 —— 卖之前必须先解决的坑

> 一句话:**现在屏幕上好看的两款字,都不能原样嵌进「要卖/要分发」的 PDF。** 定版视觉方向②用了
> 楷体(KaiTi)和 Georgia,两款都是**专有商业字体**(前者微软/中易,后者微软)。作品集自己看没事;
> 一旦这张海报要卖、要送、要放进任何别人能下载的地方,就等于**再分发字体**,必须换成开源可嵌入款。
> **别等 PDF 管线做完才发现不能卖 —— 现在就锁定替换方案。**

---

## 1. 坑在哪(为什么系统字体不能卖)

| 现在用的(屏幕) | 性质 | 嵌进要卖的 PDF 会怎样 |
|---|---|---|
| **楷体 KaiTi / STKaiti** | 微软(Windows)/华康·中易 专有 | 无嵌入分发授权 → 侵权 |
| **Georgia**(老式数字那款衬线) | 微软专有(Matthew Carter 设计) | 无嵌入分发授权 → 侵权 |

"嵌进 PDF" = 把字体的字形数据打包进文件一起发出去,这在法律上就是**再分发(redistribution)**,
按字体的商用/嵌入条款走。系统自带 ≠ 可随意嵌入分发。

## 2. 替换方案(开源、可商用、可嵌入)

| 角色 | 换成 | 许可 | 备注 |
|---|---|---|---|
| 楷体(月份名、里程碑标签) | **霞鹜文楷 LXGW WenKai** | SIL OFL 1.1 | 楷味开源字,正是方向②要的笔锋 |
| 衬线+老式数字(年份、刻度) | **EB Garamond** | SIL OFL 1.1 | 真·老式数字(oldstyle figures)、暖编辑气 |

两款都是 OFL,允许嵌入、允许再分发、允许商用、允许改(subset)。**但 OFL 有三条硬纪律必须照做:**

### OFL 三条纪律(照做才算合规)—— 2026-08-11 已读两款 OFL.txt 正文核实

1. **许可正文必须随字体走。** 每份分发拷贝(含嵌进 PDF 的子集)都要随附版权声明**与 OFL 全文**。
   Google Fonts 网页字体和 `pyftsubset` 默认会剥掉字体里的 nameID 13(内嵌许可),所以许可正文
   **必须以独立文本文件**放在 `fonts/LICENSES/` 里跟着走。
   ✅ **已落地**:`public/fonts/LICENSES/EBGaramond-OFL.txt`、`LXGWWenKai-OFL.txt` 均已随产物放置。
2. **保留字体名(RFN)不能用在改过的版本上。** subset(裁字)= 制造 Modified Version,RFN 随之激活。
   **验 RFN 读 OFL.txt 正文,不读二进制 name 表。** 读后实测结论:
   - **EB Garamond**:copyright 声明**无** Reserved Font Name → 子集嵌入无命名限制,干净。
   - **霞鹜文楷**:声明了 RFN(`'LXGW'` 等),**且附加许可只覆盖「web 字体投递(WOFF/WOFF2)」用途,
     明确排除「做成可安装的桌面字体」**。→ 嵌进「要卖的 PDF」既非 web 投递、又非桌面安装字,属**灰区**。
     保守落地:① 子集内部**改名避开 `LXGW`/保留名**(如 `Calendar Kai Subset`),导出后核对嵌入子集 name 表;
     ② OFL.txt 随 PDF 分发;③ **商用规模化前按作者原话去问 @lxgw 确认 PDF 嵌入在范围内**,别自行扩大解释。
3. **逐个核对,不类推。** 同族不同命。两款已各自读 OFL.txt 核实(见上)。

## 4. 印刷级 PDF 规格(导出的那张纸 = 产品主角)

| 项 | 值 | 说明(人话) |
|---|---|---|
| 成品尺寸(trim) | **A1 841 × 594 mm 横向** | 裁切后的最终大小 |
| 出血(bleed) | **3 mm** 四边 | 底色/图延伸到裁切线外 3mm,裁歪了也不露白边 |
| 页面(media)含出血 | **847 × 600 mm** | = trim + 2×3mm |
| 裁切标(crop marks) | 四角,离 trim 角 3mm 起、长 ~5mm | 印厂照这个裁 |
| 套准标(registration) | 顶边中点(可选) | 多色套印对齐用 |
| 颜色 | **CMYK-aware** | 屏幕是 RGB;印刷是 CMYK,导出要按印刷色空间给值,别让印厂瞎转 |
| 字体 | **子集嵌入(subset embed)** | 印厂机器没你的字,不嵌就变豆腐块/替换字 |
| 分辨率 | 矢量优先 | 文字/线/色块全矢量,无限放大不糊;纸纹噪声按需栅格化 |

**技术选型(拟定):用 `pdf-lib` + `@pdf-lib/fontkit` 在 JS 里直接生成 PDF。** 理由:能精确到 mm 设页面/出血、
能矢量画裁切标、能给 **CMYK** 色值(`cmyk()`)、能 subset 嵌字。这条路是「把 HTML 打印成 PDF」(Ctrl+P/
Electron printToPDF)做不到的——后者只给 RGB、没真出血/裁切标、嵌字不可控。参考几何范本:
`eriknyquist/generate_life_calendar`(PyCairo 生成印刷级海报的排版几何)。

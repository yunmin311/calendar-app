# 视觉方向 · 锁定(Anchor)

**2026-08-11 用户定版:方向② 暖·手作·编辑。** 源稿 `design/2026-08-11-poster-directions/concept-2-editorial.html`。

## 骨架(三方向共用,已定)
- **12 行 = 12 个月**,每行一条日子从左到右的横向长条;顶部 1–31 日刻度,左侧月份栏。
- 每月起始星期不同 → 周末在整幅自动排成**斜向条纹**(= 品牌节奏/负空间,不是装饰,是结构)。
- 真实 **A1 横向 841×594mm** 比例排版,不按屏幕宽度随意撑。

## 方向②的性格(性格预算只花一处:楷体月份 + 纸纹材质)
- **底=暖纸**(非奶油白,偏麦色)+ **真实纸纹**(内嵌 SVG 湍流噪声、正片叠底、极低透明度;**不是背景渐变**)。
- **只有横向发丝线,没有竖网格线** → 年鉴/文本感(区别于①的强网格、③的粗黑框)。
- **月份名=楷体**(大字号出笔锋);年份/刻度=衬线**老式数字**。字号两极制:大而轻的月份名 vs 小而稳的数字。
- **强调=赭黄 + 墨绿**(刻意避开 AI 俗脸「奶油底+衬线+赤陶」)。
- **里程碑=赭黄星标(✳)+ 楷体斜排标签**,作排版锚点;**分类密度=画面纹理**(周末暖底、冲刺期底纹、远行淡青)。

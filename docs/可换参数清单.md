# 可换参数清单 —— 给出稿方(Creative OS 设计对话)

> **一句话**:你给的是**一组值**,不是一次改代码。把下面这张表填好交回来,
> 我照着换一副样子;原来那套「暖·手作·编辑」留给印刷,不受影响。
>
> 硬约束(我这边):**输出会直接显示在 CO 界面里,视觉必须和 CO 一致。**

## 怎么用(不改代码)


## 一、颜色(共 7 项 + 分类色)

| 参数 | 现值(B 暖·编辑) | 管什么 | 出现在哪 |
|---|---|---|---|
| `paper` | `#f4efe3` 麦纸 | 纸底 | 所有出口的底 |
| `paper2` | `#eaded0` 略深纸 | 周末底纹 / 活动带空格底 | 整年图、活动带 |
| `ink` | `#20201b` 墨 | 正文、日号、报头 | 全部 |
| `inkSoft` | `#8c8371` 淡墨 | 次要文字、刻度、图例字 | 全部 |
| `line` | `#d9cfb9` | 格线、分隔线 | 全部 |
| `seal` | `#9e3b32` 朱砂 | 里程碑印、周日刻度 | 全部(CO 场景没有里程碑,只剩周日刻度) |
| `palette` | 见下 | **分类色**:每个活动类型一个色 | 日格、图例、占比条、横条 |

**分类色 `palette`** —— CO 真有的三类,现值:

| 类型 | 现值 | 取意 |
|---|---|---|
| `收灵感` | `#6f8ea0` 花青 | 从外面收进来的,冷一点 |
| `分析` | `#b5794f` 赭石 | 案头拆解,暖褐 |
| `整理` | `#86a07e` 石绿 | 归置收束,沉静 |

> 这三色是我按矿物色系挑的(没登记的类型会走哈希派生色,实测抽到紫+苍绿+秋香,
> 紫在暖麦纸上发塑料,所以改成手挑)。**你可以整组换掉。**
> 注意:格子会按当天的忙闲加透明度(0.4–1.0),所以给的色**要偏实**,落纸自然会柔。

## 二、质感(共 6 项)

| 参数 | 现值 | 管什么 |
|---|---|---|
| `texFreq` | `0.06` | 纸面斑驳的疏密(越大越细碎) |
| `texOp` | `0.15` | 斑驳的浓度 |
| `speckle` | `true` | 要不要剥蚀白飞点 |
| `speckleOp` | `0.22` | 飞点浓度 |
| `mono` | `false` | 单色墨模式:`true` 则不用分类色,只用墨深 |
| `weekendTint` | `true` | 整年图上周末是否加一层浅底 |

另有**四套现成的手工质感**可整套替换(与上面的参数并行,写在 `texture` 而不是皮肤里):

```js
createRecord(acts, { year: 2026, variant: CO_SKIN, texture: 'handdrawn' });
createRecord(acts, { year: 2026, variant: CO_SKIN, texture: { name: 'topographic', lineOp: 0.3 } });
```

| 预设 | 是什么 | 可调参数 |
|---|---|---|
| `rubbing` 拓质(默认) | 斑驳 + 剥蚀白飞点 | `mottleFreq/mottleOp/speckle/speckleFreq/speckleOp` |
| `tiedye` 扎染 | 染心晕开 + 湍流揉皱 + 折痕环 | `opacity/warp/warpFreq/rings/ringOp/centers[]` |
| `handdrawn` 手绘 | 铅笔颗粒 + 方向排线 | `grainOp/grainK/grainOff/hatch/hatchOp/tint` |
| `topographic` 拓扑 | 噪声阈值化成等高线 | `freq/bandCount/lineOp/oct/seed/tint` |
| `none` 素纸 | 干净的纸,一点纹理都不要 | — |

**拖滑块调**:`design/2026-08-19-texture-module/02-质感调参台.html` 双击就开
(不用装东西、不用起服务),调顺眼了页面下方直接吐出可粘贴的配置。

> 质感参数只有一条规则:**按 A1 长条为基准写,载体只换算噪声频率,别的照搬**。
> 所以同一份配置在整年图和统计卡上花纹密度看起来一致。

## 三、文案(共 5 项)

| 参数 | 现值 | 出现在哪 |
|---|---|---|
| `era` | `'2026'` | 整年图报头大字(单色墨版用干支,如 `'丙午'`) |
| `title` | `'活动留痕'` | 报头标题 |
| `sub1` | `'CO · 一纸看尽'` | 报头右上第一行 |
| `sub2` | `'Record Edition'` | 报头右上第三行 |

## 四、**不能**换的(换了要改代码,先跟我说)

- **版面几何**:A1 长条 841×594mm、月卡 210×280mm、12 月行 × 31 日列、7 列周历 —— 印刷规格锁死的。
- **字体**:屏幕用系统字;印刷必须是可嵌入的开源款(EB Garamond + 霞鹜文楷),这是版权硬约束。
- **视觉语言的语义**:墨深 = 那天比别天忙不忙 · 素纸留白 = 没做 · 朱砂印 = 里程碑。
  颜色可以全换,但"深浅代表忙闲"这件事不能换,否则图就读不成了。
- **出血 / 裁切标 / CMYK**:印刷规格,只在 PDF 出口生效。

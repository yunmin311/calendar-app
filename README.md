# 2026 线性日历

一个功能强大的年度规划工具，采用线性日历展示方式，帮助你更直观地规划和管理 2026 年度的目标和任务。

## ✨ 特性

- 📅 **线性日历展示** - 一眼看遍整年日期，科学规划年度时间
- ✍️ **文字输入** - 为每一天添加详细的计划和备忘
- 🎨 **颜色标记** - 用不同的颜色标记不同类型的事项，视觉化管理
- 🖨️ **打印导出** - 支持将日历导出为 PDF 或打印纸质版本
- 🎯 **跨平台** - 支持 Windows、macOS 和 Linux 系统

## 🚀 快速开始

### 环境要求

- Node.js 16.0+
- npm 或 yarn

### 安装

```bash
# 克隆项目
git clone https://github.com/yunmin311/calendar-app.git

# 进入项目目录
cd calendar-app

# 安装依赖
npm install
